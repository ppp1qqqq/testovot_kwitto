# Правила для ассистента

Сервис принимает оплату курсов: тарифы, платежи, вебхук банка. Код в `app/`, тесты в `tests/`.

Деньги:
- все суммы в копейках, тип `int`. Никаких `float` ни в API, ни в базе, ни в промежуточных расчётах;
- расчёт скидки и графика рассрочки живёт в `app/pricing.py`, в роутерах арифметики быть не должно;
- сумма графика рассрочки всегда ровно равна `amount`, лишние копейки идут в первые платежи.

Статусы:
- разрешённые переходы описаны только в `ALLOWED_TRANSITIONS` (`app/enums.py`), не дублируй их в другом месте;
- запрещённый переход отвечает 409 с телом ровно `{"error": "invalid_transition"}` и не меняет статус.

API:
- ошибки валидации оставляем в стандартном формате FastAPI (422), свой формат не придумываем;
- повтор `POST /payments` с тем же `Idempotency-Key` возвращает существующий платёж с кодом 200.

Перед тем как сказать «готово»:
- `ruff check . && ruff format --check . && pytest -q` должны проходить;
- на новое поведение нужен тест, и он проверяет результат (суммы, статус в базе), а не только код ответа;
- если тест прошёл с первого раза, сломай код, который он проверяет, и убедись, что тест упал.
